🏗 Cấu trúc phân cấp dữ liệu

Project (Dự án)
   └─ Goal (Mục tiêu: tiền | số lượng | %)
   └─ Task (Đầu việc)
         ├─ status: idea → first_draft → beta → edit → published
         ├─ assigned_to: User (nhiều thành viên)
         └─ Attachments (file đính kèm)
   └─ members: User[] (phân quyền: owner, manager, member)

PackageCông dụngCài đặt

🗄 Database

MySQL 8+ — phù hợp cho quan hệ phức tạp (project → task → member)
Redis — cache search, session, queue jobs (import/export nặng)

💻 Lệnh & Cài đặt
Copy nhanh các lệnh bash để setup dự án Laravel từ đầu.

🚀 Khởi tạo project

composer create-project laravel/laravel my-app cd my-app cp .env.example .env php artisan key:generate

📦 Cài packages cần thiết

composer require laravel/sanctum composer require spatie/laravel-permission composer require spatie/laravel-medialibrary composer require maatwebsite/excel composer require laravel/scout composer require meilisearch/meilisearch-php http-interop/http-factory-guzzle

🏗 Publish & Migrate

php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider" php artisan vendor:publish --provider="Spatie\Permission\PermissionServiceProvider" php artisan vendor:publish --provider="Spatie\MediaLibrary\MediaLibraryServiceProvider" --tag="medialibrary-migrations" php artisan migrate

🔧 Filament Admin Panel

composer require filament/filament php artisan filament:install --panels php artisan make:filament-user

📁 Tạo Models & Migrations

php artisan make:model Project -mfsc php artisan make:model Goal -mfsc php artisan make:model Task -mfsc php artisan make:model ExcelFormula -mfsc php artisan make:model ProjectMember -m

🔑 .env quan trọng

DB_CONNECTION=mysql DB_HOST=127.0.0.1 DB_DATABASE=laravel_app DB_USERNAME=root DB_PASSWORD= SCOUT_DRIVER=meilisearch MEILISEARCH_HOST=http://127.0.0.1:7700 MEILISEARCH_KEY= FILESYSTEM_DISK=public

🐳 Chạy Meilisearch bằng Docker

docker run -d \ --name meilisearch \ -p 7700:7700 \ -e MEILI_MASTER_KEY=yourMasterKey \ getmeili/meilisearch:latest

🔍 Scout search trong ExcelFormula

# Trong ExcelFormula model, implement Searchable: # use Laravel\Scout\Searchable; # toSearchableArray() trả về: name, syntax, description, category, tags php artisan scout:import "App\Models\ExcelFormula"
